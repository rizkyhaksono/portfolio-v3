I removed avoidable work from common page loads and reviewed the main interactions with a keyboard.

- Improved image sizing and lazy loading.
- Reduced repeated requests where cached data is sufficient.
- Added clearer labels and focus states.
- Fixed several mobile overflow problems.

I deliberately removed the old synthetic performance numbers; changes are only described when they are represented by the implementation.
